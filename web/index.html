Find the set.

I use three index bits to pick one of eight sets. Address 0043 points to set 0. I don’t search the whole cache.

Check the tag.

I compare both ways at once. A valid block with tag 002 is a match. An empty slot can never hit.

Pick the byte.

The last two bits are 11: byte offset 3. I take the fourth byte, 43, from the block. The other bytes stay put.
